# 파이어 엠블렘 if DLC 한국어 번역·검수 통합 작업 지침

> 대상: 《파이어 엠블렘 if》 DLC 대사(특히 인연의 백야제·인연의 암야제) 일본어 원문 → 한국어 번역/검수  
> 기준: **일본어 원문은 의미의 출발점, 정발 한국어판은 캐릭터 말투·호칭·용어·현지화 방식의 최우선 기준**  
> 목적: 문학적으로 가장 매끈한 새 번역이 아니라, **“정발판의 같은 캐릭터가 DLC에서도 그대로 말하는 것처럼 보이는 번역”**을 만든다.

---

## 0. 절대로 생략하면 안 되는 작업 원칙

### 0-1. 대응하는 정발 지원회화를 먼저 읽는다
번역 대상 회화가 특정 인물 간의 대화라면 **번역을 시작하기 전에** 대응하는 정발판 본편 지원회화를 실제로 찾아서 읽는다.

특히 다음은 추정으로 처리하면 안 된다.

- 부모 ↔ 자식
- 부부
- 형제·자매
- 주인공 ↔ 캐릭터
- 본편 지원회화의 특정 사건·대사·농담을 재언급하는 DLC
- 캐릭터의 평소 말투와 가족에게 쓰는 말투가 달라질 가능성이 있는 경우

**“이 캐릭터는 평소 존댓말 캐릭터니까 가족에게도 존댓말이겠지” 같은 추론 금지.**  
반대로 **“부모 자식은 보통 반말이겠지” 같은 추론도 금지.**

반드시 정발 파일을 실제로 확인한다.

### 0-2. 효율을 이유로 표본만 보고 패턴을 일반화하지 않는다
몇 명을 확인한 뒤 나머지도 같을 것이라고 가정하지 않는다.

예:
- 사쿠라가 평소 존댓말을 쓴다고 해서 자식에게도 존댓말이라고 추정 금지.
- 미타마가 평소 격식 있는 말투라고 해서 부모에게 반말/존댓말 여부를 추정 금지.
- 셀키처럼 존댓말을 기본으로 하되 짧은 응답에서 `응`, `아니야` 등이 섞이는 경우가 있으므로 **“존댓말 O/X”만으로 모든 문장을 기계적으로 바꾸지 않는다.**

### 0-3. 작업 순서
각 MID/회화마다 아래 순서를 지킨다.

1. 일본어 DLC 원문 확인
2. 화자·상대·관계 확인
3. 대응 정발판 지원회화 파일 검색
4. **그 파일을 실제로 읽고**
   - 자식→부모 존댓말 여부
   - 부모→자식 존댓말 여부
   - 호칭
   - 어미
   - 캐릭터 특유의 감탄사/말버릇
   를 먼저 기록
5. DLC가 본편 대사를 재언급하는지 확인
6. 재언급이면 **정발판 문구 재사용**
7. 번역
8. 조사 제어코드 적용
9. 제어코드·줄바꿈·형식 대조
10. 일본어 잔존·전각 공백·대시·활용·호칭 최종 검사
11. 최종본만 납품

---

# 1. 번역의 기준

## 1-1. 우선순위
번역 판단 우선순위는 다음과 같다.

1. **정발판 동일 캐릭터의 실제 표현**
2. **정발판 동일 관계(부모·자식, 부부 등)의 실제 말투**
3. 정발판 공식 용어·고유명사
4. 일본어 원문의 의미·감정·대화 기능
5. 자연스러운 한국어
6. 원문의 음가·어순

일본어 문장을 그대로 직역하는 것보다 **정발판 캐릭터 정체성을 유지하는 것이 우선**이다.

## 1-2. 과잉 의역도 금지
정발판 자체에 약간 직역투가 남아 있다면, 정발판에서 충분히 나올 법한 문장을 굳이 현대적인 자연어로 크게 뜯어고치지 않는다.

목표는:
> “잘 쓴 한국어 소설”이 아니라 “정발판 if에 실제로 들어 있었을 법한 DLC 대사”

이다.

## 번역 시 사용법

1. DLC에서 자식이 **고정 부모**와 대화한다면 위 표로 1차 말투 방향을 고정한다.
2. 실제 번역 전에 해당 정발 K `*_親子.txt`를 다시 열어:
   - 호칭
   - 어미
   - 짧은 응답의 예외
   - 해당 장면과 비슷한 감정 상태의 말투
   를 확인한다.
3. DLC에서 자식이 **가변 부모**와 대화한다면 이 표로 추정하지 않는다. 해당 가변 부모 지원회화를 개별 대조한다.
4. 일본어 원문의 존댓말 방향과 정발 K가 다르면 **정발 K를 우선**한다.
5. 독립 감탄사·시구·인용문·연기 대사는 문장 전체의 존댓말 판정과 분리해서 본다.

## 절대 금지

- `부모 자식이니까 반말일 것`이라고 추정
- `캐릭터가 평소 존댓말 캐릭터니까 가족에게도 존댓말일 것`이라고 추정
- 고정 부모 표를 가변 부모에게 그대로 적용
- `응` 한 번 나온 것을 보고 전체 관계를 반말로 판정
- 일본어 원문만 보고 정발판의 존댓말 현지화를 무시


### 운용상 주의

- `존댓말 중심`은 기본이 존댓말이지만 짧은 반말 응답이 섞이는 유형이다.
- **고정 부모→자식은 22종 전부 반말**이다.
- 이 표는 고정 부모용이다. 가변 부모는 해당 `*_親子.txt`를 개별 확인한다.

# 3. 정발판 대사 재사용

DLC가 본편 지원회화의 대사나 사건을 명시적으로 회상한다면 새로 번역하지 않는다.

예:
- 오보로의 본편 지원회화 대사를 DLC에서 다시 인용할 경우 정발판 표현 그대로 재사용.
- 플로라가 `$Nu`에게 들었던 위로를 회상할 경우 본편 정발 문구를 우선 재사용.
- 크림슨의 고백/청혼 문구가 재등장하면 본편 정발 표현을 재사용.
- 오펠리아의 기술명·명명 놀이도 본편 정발 용어를 우선한다.

**일본어 원문이 같거나 의도적으로 본편을 콜백하는데 번역을 새로 만드는 것은 금지.**

# 4. 조사 제어코드 `$KrP`

정발판의 가변 이름 조사 제어코드:

| 코드 | 기능 |
|---|---|
| `$KrP1|` | `(은)는` |
| `$KrP2|` | `(을)를` |
| `$KrP3|` | `(이)가` |
| `$KrP4|` | `(과)와` |
| `$KrP5|` | `(으)` |
| `$KrP6|` | `(이)` |

## 4-1. `$Nu` 같은 가변 문자열 뒤 조사는 고정해서 쓰지 않는다
잘못:
- `$Nu가`
- `$Nu를`
- `$Nu는`
- `$Nu와`

정발식:
- `$Nu$KrP3|`
- `$Nu$KrP2|`
- `$Nu$KrP1|`
- `$Nu$KrP4|`

## 4-2. `$KrP5|`
받침에 따라 `(으)`가 필요한 구조에 사용.

예:
- `$Nu$KrP5|로`

## 4-3. `$KrP6|`
받침에 따라 `(이)`가 필요한 구조에 사용.

예:
- `$Nu$KrP6|랑`
- `$Nu$KrP6|야`
- `$Nu$KrP6|라고`
- `$Nu$KrP6|라는`

## 4-4. 고정 호칭 뒤는 무조건 조사 코드로 바꾸지 않는다
예:
- `$Nu님이`
- `$Nu씨에게`
- `$Nu 오라버니는`

이 경우 조사가 붙는 대상은 `$Nu` 자체가 아니라 `님`, `씨`, `오라버니`라는 고정 문자열이므로 필요 없이 `$KrP`를 삽입하지 않는다.

## 4-5. 최종 검사
결과물에서 다음 패턴을 검색한다.

- `$Nu가`
- `$Nu는`
- `$Nu를`
- `$Nu와`
- `$Nu랑`
- `$Nu야`
- `$Nu라고`
- `$Nu라는`
- `$Nu로`

문맥상 가변 조사라면 `$KrP`로 처리한다.

# 5. 제어코드와 원문 구조

## 5-1. 절대 임의 변경 금지
다음 요소는 원문 구조를 최대한 그대로 보존한다.

- `MID_...` ID
- `$Ws...`
- `$Wm...`
- `$Wa...`
- `$Svp...`
- `$E...`
- `$k`
- `$p`
- `\n`
- `$t`
- `$w`
- `$Wd`
- `$a`
- `$Wc`
- `$Sbv`
- `$Fo`
- `$Fi`
- `$Ssp`
- 기타 엔진 제어코드

코드 내부의 일본어 캐릭터명은 **번역하지 않는다.**

예:
`$Wsカンナ女|` → 그대로 유지.

## 5-2. 줄바꿈
원문의 `\n`, `$k`, `$p` 구조는 특별한 이유가 없으면 유지한다.

최종 검사에서는 원문과 번역문의:
- `\n` 개수
- `$k` 개수
- `$p` 개수
- `$Ws` 개수
- `$Wm` 개수
- `$Svp` 개수
- 전체 제어코드 순서

를 대조한다.

## 5-3. “제어코드를 보존한다”와 “조사 코드를 새로 적용한다”는 별개
일반 제어코드는 원문 그대로 보존한다.  
단, 한국어판에서 필요한 `$KrP`는 **정발판 한국어 출력 규칙에 맞춰 적용**한다.

---

# 6. 전각 공백(U+3000)

## 6-1. 일반 한국어 가시 텍스트에는 사용 금지
잘못:
`얍!　얍얍!`

올바름:
`얍! 얍얍!`

일본어 원문의 전각 공백을 한국어 문장에 기계적으로 끌고 오지 않는다.

## 6-2. 예외
원문/기존 정발 형식에서 **인용문 두 번째 줄 들여쓰기 등 명백한 서식 목적**으로 유지해야 하는 경우만 예외로 검토한다.

그 외에는 최종 결과물의 U+3000을 코드 포인트 기준으로 전수 검사한다.

---

# 7. 대시

**`—`(EM DASH) 사용 금지.**

사용:
- `―` (HORIZONTAL BAR)

예:
- `그런 거였구나―` ✅
- `그런 거였구나—` ❌

최종 검사에서 `—`가 0개인지 확인한다.

---

# 8. 일본어식 감탄사 음차 금지

일본어 감탄사를 글자 단위로 옮기지 않는다.

금지 예:
- `はわわ` → `하와와`
- `あわわ` → `아와와`
- `ひゃあ` → `햐아`
- `うわわわ` → `우와와와`

번역 대상은 **문자열이 아니라 그 순간의 감정 기능**이다.

우선순위:
1. 정발판 같은 캐릭터가 실제로 쓰는 감탄사
2. 한국어에서 해당 캐릭터에게 자연스러운 감탄사
3. 장면의 감정·강도
4. 일본어 원문의 음가

예:
- 펠리시아 `はわわ...` → `으아아...`, `흐아아...`
- `あわわ` → `어어어…`, `으아아…`, `아, 아니…!`
- `ひゃあっ` → `꺅!` / `으악!` (상황에 따라)
- `うわわわ` → `으아아악!`, `어어어?!`
- `わわっ` → `앗!`, `어엇!`, `으앗!`
- `あたたた` → `아야야야!`

---

# 9. 말더듬기 표현은 함부로 교정하지 않는다

다음과 같은 표현은 **오타가 아니라 말을 하다가 첫 음절에서 걸리는 연기**다.

정상 예:
- `카, 칸나`
- `괘, 괜찮아`
- `벼, 별로`
- `저, 정말`
- `어, 얼마`
- `가, 갑자기`
- `마, 말 안`
- `무, 물론`
- `호, 혹시`
- `이, 일단`

이걸 다음처럼 “완성 음절”로 바꾸지 않는다.

- `카, 칸나` → `칸, 칸나` ❌
- `괘, 괜찮아` → `괜, 괜찮아` ❌

**말더듬기의 첫 토막은 실제 음절 완성 여부가 아니라 발화가 끊긴 지점을 표현한다.**

---

# 10. 한국어 활용·문법

사소해 보여도 반드시 기계적으로 점검한다.

예:
- `뒤집어쓰다 + -ㄴ다고` → `뒤집어쓴다고`
- `쓰다 + -ㄴ다고` → `쓴다고`
- `가다 + -ㄴ다고` → `간다고`
- `먹다 + -는다고` → `먹는다고`
- `입다 + -는다고` → `입는다고`

특히 검사:
- `-ㄴ다고 / -는다고`
- `-냐고`
- 과거형
- 높임법
- 조사 결합
- 받침 유무에 따른 형태

사용자가 특정 표현을 지적했을 경우 먼저 **형태소·활용 자체가 맞는지**부터 확인하고, 해석론으로 빠지지 않는다.

---

# 11. 일본어 수동태

일본어 수동태를 한국어에 기계적으로 보존하지 않는다.

한국어에서 자연스럽다면 능동문으로 재구성한다.

다만 문법 오류 지적을 받았을 때 “수동태 번역 문제” 같은 큰 이론으로 돌리지 말고, 우선 해당 어절의 문법부터 고친다.

# 12. 정발판 고유 표기

## 12-1. `님`, `씨`

- `하야토씨`

표준 맞춤법에 맞추겠다고 임의로 띄어쓰지 않는다.

## 12-2. 호칭별 예외는 정발 파일 그대로
예:
- 사쿠라의 `$Nu 오라버니`는 **띄어쓰기 유지**.

# 20. 절대 금지

1. 몇 명만 확인하고 나머지 말투를 패턴 추정
2. 일본어 원문 존댓말을 그대로 따라가면서 정발 가족 말투를 무시
3. 평소 캐릭터 말투만 보고 부모·자식 말투 결정
4. 본편 콜백 대사를 검색하지 않고 새로 번역
5. `$Nu가`처럼 가변 변수 뒤 조사를 하드코딩
6. 제어코드 개수/순서를 검증하지 않고 납품
7. 전각 공백을 일본어 원문에서 그대로 복사
8. `—` 사용
9. `하와와`, `아와와` 식 일본어 감탄사 음차
10. `카, 칸나`를 `칸, 칸나`처럼 멋대로 “교정”
11. 사용자가 이미 확정한 정발식 `님/씨` 붙여쓰기를 표준 맞춤법으로 수정
12. 실제로 수행하지 않은 FEFTS 폭 검사를 수행했다고 말하기
13. 사용자가 요청하지 않았는데 GitHub 커밋/수정
14. 검수라는 명목으로 멀쩡한 문장을 취향에 따라 대량 재작성
15. “효율상 이 정도면 비슷하겠지”라는 이유로 참조 파일 확인 생략

# 21. 작업 보고 방식

번역 결과와 함께 보고할 가치가 있는 것은 다음 정도다.

- 말장난을 강하게 현지화한 곳
- 본편 정발 대사를 그대로 재사용한 곳
- 일본어와 정발판의 존댓말 방향이 달라 정발판에 맞춘 곳
- 용어가 애매해 정발판 검색으로 결정한 곳
- 의도적으로 형식을 바꾼 곳

일반적인 문장 하나하나에 장황한 설명을 붙이지 않는다.

# 22. 가장 중요한 한 문장

> **추정하지 말고, 대응하는 정발판 파일을 실제로 열어 본 다음 번역한다.**

이 절차를 생략하면 번역 자체가 자연스러워 보여도 캐릭터 관계·존댓말·호칭에서 대형 오류가 발생할 수 있다.
