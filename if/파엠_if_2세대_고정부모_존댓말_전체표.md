# 파이어 엠블렘 if 2세대 고정 부모 존댓말 전체 기준표

> 기준 자료: `if/파이어 엠블렘 if 대사집 (K)`의 각 고정 부모 `*_親子.txt`  
> 용도: DLC 번역 전에 **자식→고정 부모 / 고정 부모→자식의 존댓말 방향과 부모 호칭을 즉시 확인**하기 위한 참조표.

## 핵심 규칙

- 아래 판정은 **정발판 고정 부모 지원회화를 실제로 확인한 결과**다.
- `존댓말 중심`은 기본 문장 체계가 존댓말이지만 `응`, `아니야` 같은 짧은 응답에서 반말형이 섞이는 경우다.
- **고정 부모→자식은 이 표의 22종 전부 반말**이다.
- 자식→고정 부모는 일률적이지 않다.
  - 양방향 반말: **칸나(여), 칸나(남), 퍼시**
  - 그 외: 대체로 자식→부모 존댓말
  - 셀키·솔레이·니나: 존댓말 중심 + 짧은 반말 응답 혼용
- 이 표를 **가변 부모 조합에 일반화하면 안 된다.** 자식과 가변 어머니/아버지의 DLC 회화를 번역할 때는 반드시 해당 `<자식>_<부모>_親子.txt`를 별도로 열어 본다.

## 번역 시 사용법

1. DLC에서 자식이 **고정 부모**와 대화한다면 위 표로 1차 말투 방향을 고정한다.
2. 실제 번역 전에 해당 정발 K `*_親子.txt`를 다시 열어:
   - 호칭
   - 어미
   - 짧은 응답의 예외
   - 해당 장면과 비슷한 감정 상태의 말투
   를 확인한다.
3. DLC에서 자식이 **가변 부모**와 대화한다면 이 표로 추정하지 않는다. 해당 가변 부모 지원회화를 개별 대조한다.
4. 일본어 원문의 존댓말 방향과 정발 K가 다르면 **정발 K를 우선**한다.
5. 독립 감탄사·시구·인용문·연기 대사는 문장 전체의 존댓말 판정과 분리해서 본다.

## 절대 금지

- `부모 자식이니까 반말일 것`이라고 추정
- `캐릭터가 평소 존댓말 캐릭터니까 가족에게도 존댓말일 것`이라고 추정
- 고정 부모 표를 가변 부모에게 그대로 적용
- `응` 한 번 나온 것을 보고 전체 관계를 반말로 판정
- 일본어 원문만 보고 정발판의 존댓말 현지화를 무시
